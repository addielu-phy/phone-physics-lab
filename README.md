# Phylab · 手機感測・電腦實驗｜盧政良 Addie Lu

Phylab（Physics + Laboratory）是以瀏覽器量測為主的高中課堂手機感測與科學探究實驗平台。結合「方格紙實驗記錄簿」與「暖米色學術刊物」雙風格視覺（儀器藍 `#1a6fd4` × 朱紅 `#B8432F`），每台電腦獨立配對一支手機，量測結束後可檢視即時圖表、多輪統計擬合並手動下載完整 Excel 實驗記錄簿。支援繁中／英文與亮色／暗色主題切換。

## 課堂操作流程

1. **選擇與配對**：在電腦開啟公開 HTTPS 網站 → 選擇實驗模組 → 手機掃描右側 QR Code。
2. **授權與校準**：手機點擊「啟用感測器」並允許瀏覽器權限 → 依指引穩定擺放後可做相對 0° 校準。
3. **量測與匯出**：由電腦控制開始、暫停／繼續、結束量測 → 檢視即時曲線與頻譜／擬合分析 → 手動下載 Excel（`.xlsx`）。

## 22 項實驗模組（6 大分類）

- **運動與姿態**：加速度（含重力）、陀螺儀（角速度）、傾角（水平儀）、向心加速度、半徑擬合（$a_c - \omega^2$）、運動碼錶
- **振動與波動**：單擺（推導 $g$）、彈簧振動、彈簧常數 $k$、加速度頻譜、振動分析、彈性碰撞反彈（聲學秒錶）
- **聲音與頻率**：聲音頻譜（FFT 與主頻）、主頻歷史、聲學秒錶
- **光學與影像**：相機相對亮度、相機 RGB 色彩與剖面、光學秒錶、環境照度計（lx）
- **定位與空間**：GPS 位置、位移與速度追蹤
- **磁場與其他**：三軸磁力計（$\mu\text{T}$）、教師自訂實驗（JSON Manifest 設定）

## 感測器與網路注意事項

- **瀏覽器要求**：Android 請使用 Chrome（確認「設定 → 網站設定 → 動作感應器」已允許）；iPhone 請使用 Safari 並允許動作與方向存取。若從 LINE 等通訊軟體點開，請切換至系統外部瀏覽器。
- **連線機制**：預設透過 PeerJS 公共信令與 WebRTC 點對點直連（使用 Cloudflare／Google STUN）；亦支援設定 `VITE_RELAY_URL` 啟用 WebSocket 中繼備援。
- **試用示範模式**：若無手機在手邊，可點擊「試用示範」體驗全部 22 項實驗模組、即時圖表、多輪比較與 Excel 匯出（示範數據均明確標示 `DEMO`，與實測資料嚴格區隔）。
